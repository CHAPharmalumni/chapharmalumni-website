# 차 의과학대학교 약학대학 총동문회 홈페이지 (시안)

회장님 초안(cha-pharmacy-alumni-design.inyoung3931.chatgpt.site, 2026-11-23 내려받음)의 디자인을 그대로 쓰고,
게시판과 임원 글쓰기 기능을 더한 시안이다. 아직 인터넷에 공개하지 않았다.

## 내 컴퓨터에서 열어 보기

```bash
cd ~/chapharmalumni-website && python3 -m http.server 8765
```

그다음 브라우저에서 http://127.0.0.1:8765 를 연다. 맨 아래 「관리자 로그인」에 `admin@chapharmalumni.org`를 넣으면 글쓰기 버튼이 나타난다.
시안에서는 글이 그 브라우저 안에만 저장된다. 다른 컴퓨터나 다른 브라우저에서는 보이지 않는다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html`, `style.css`, `app.js` | 첫 페이지. 회장님 초안 그대로이고, 소식 목록만 게시판 글을 읽도록 바꿨다 |
| `board.html` | 게시판 목록 (소식·행사·경조사·갤러리·자료실, 검색 결과) |
| `post.html` | 글 보기, 임원에게만 수정·삭제 버튼 |
| `write.html` | 글쓰기·수정 (게시판 선택, 제목, 본문, 사진 여러 장, 맨 위 고정) |
| `about.html` | 동문회 소개 (인사말·운영진·회원 안내·문의·개인정보처리방침) |
| `board.css` | 위 하위 페이지의 디자인. 색과 글꼴은 `style.css` 값을 그대로 쓴다 |
| `js/config.js` | 게시판 목록과 글쓰기 허용 계정. 게시판을 늘리거나 줄일 때 여기만 고친다 |
| `js/store.js` | 글 저장과 로그인. 지금은 시안용(브라우저 저장). Firebase 연결 때 이 파일만 바꾼다 |
| `js/layout.js` | 모든 페이지의 머리말·꼬리말·로그인 창 |

## 본문 작성 규칙

본문은 HTML을 받지 않고 글자로만 저장한다(누군가 위험한 코드를 넣지 못하게 하려는 것).
빈 줄을 넣으면 문단이 나뉘고, `https://`로 시작하는 주소는 자동으로 링크가 된다.

## 다음 단계

1. 임원 회의에서 제작 방식이 정해지면, 동문회 계정으로 Firebase 프로젝트를 만든다(부회장이 직접).
2. `js/store.js`를 Firebase 판으로 바꾼다. 구글 로그인, 글 저장(Firestore), 사진 저장을 연결하고,
   `js/config.js`의 허용 계정 목록과 같은 내용을 Firebase 보안 규칙에도 적는다.
3. 무료 게시 서비스(GitHub Pages 또는 Cloudflare Pages)에 올리고 chapharmalumni.org를 연결한다.
